# com1182026

Práctica de Python para calcular el punto de equilibrio en unidades.

## Fórmula

\[
Q = \frac{CF}{PVU - CVU}
\]

- **CF**: costos fijos totales.
- **PVU**: precio de venta unitario.
- **CVU**: costo variable unitario.

## Uso

```bash
python3 punto_equilibrio.py
```

El programa solicita los valores de entrada y muestra la cantidad de unidades necesarias para alcanzar el punto de equilibrio.
